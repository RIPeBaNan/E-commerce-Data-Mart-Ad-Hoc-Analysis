# E-commerce Data Mart & Ad-Hoc Analysis

## Описание проекта
Данный проект представляет собой практическую работу по SQL для дата-аналитика. В рамках проекта выполнена обработка сырых данных вымышленного маркетплейса «ВсёТут», подготовлена агрегированная витрина данных (Data Mart) и решен ряд бизнес-задач (ad-hoc запросы) для выявления инсайтов о поведении пользователей.

## Стек технологий
* **СУБД:** PostgreSQL
* **Инструменты:** DBeaver
* **Ключевые навыки:** CTE (Common Table Expressions), агрегатные и оконные функции, JOIN, работа с датами (`DATE_TRUNC`, `EXTRACT`), приведение типов, условные конструкции (`CASE`).

## Выполненные задачи

### 1. Разработка витрины данных (Data Mart)
На основе сырых таблиц сформирован единый слой данных (витрина), агрегирующий метрики по каждому пользователю из топ-3 регионов:
* Временные рамки активности (дата первой/последней покупки, lifetime).
* Финансовые метрики (сумма покупок, средний чек).
* Пользовательский опыт (средняя оценка отзывов).
* Предпочтения по оплате (доля отмен, использование рассрочек и промокодов).

### 2. Ad-hoc аналитика
* **Сегментация:** Разделение покупателей на группы по количеству покупок. Выявлено, что ядро маркетплейса составляют клиенты с одним заказом (низкий Retention).
* **Ранжирование VIP-клиентов:** Выделение топ-15 пользователей с 3+ заказами по среднему чеку. Практически все топовые клиенты используют рассрочку.
* **Региональная статистика:** Анализ по регионам показал, что Москва лидирует по объему заказов, при этом около 50% всех покупок на платформе оформляется в рассрочку, а промокоды применяются лишь в 4% случаев.
* **Когортный анализ (2023 год):** Оценка активности пользователей по месяцу первой покупки. Выявлен резкий ноябрьский скачок регистраций (распродажи), сопровождающийся падением среднего рейтинга заказов из-за перегрузки логистики.

## Как запустить проект локально
1. Разверните сервер PostgreSQL.
2. Создайте пустую базу данных `data-analyst-ecom` с помощью инструмента командной строки (`createdb -U username data-analyst-ecom`) или через DBeaver.
3. Перейдите по ссылке из файла `data/dataset_link.txt` и скачайте дамп базы данных `data_analyst-ecom.sql` на свой компьютер.
4. Импортируйте выгруженный датасет через терминал, указав путь к скачанному файлу: 
   `psql -U username -d data-analyst-ecom -f /путь/к/файлу/data_analyst-ecom.sql`
5. Откройте скрипт `sql/data_analyst-ecom_cleaned.sql` в DBeaver или любой другой IDE и выполните запросы.
